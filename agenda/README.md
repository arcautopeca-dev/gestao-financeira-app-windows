# Agenda Fácil
Agenda de atendimentos para Windows — clientes, serviços, calendário dia/semana/lista,
dados e logotipo da empresa, envio de WhatsApp e e-mail. Sem senha, sem ativação, 100% open source (MIT).
Os dados ficam no computador do usuário (`%APPDATA%\Agenda Fácil\agenda.json`).
Para rodar: `npm install && npm start` · Para gerar o instalador: `npm run dist`.
