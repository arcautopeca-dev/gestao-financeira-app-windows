# Agenda Oficina
Agendamento de consertos e controle de ordens de serviço (OS) para oficina mecânica — Windows.
Mecânicos, clientes (nome/telefone/endereço), veículo (modelo, cor, ano, motor, placa), defeito, prazo e meta,
motivo de atraso, painel de métricas, WhatsApp com histórico por OS, finalizado/entregue e aviso de retirada.
Sem senha, sem ativação, open source (MIT). Dados em `%APPDATA%\Agenda Oficina\oficina.json`.
`npm install && npm start` para rodar · `npm run dist` para gerar o instalador.
